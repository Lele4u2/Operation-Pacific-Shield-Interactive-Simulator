
# ✈️ AFEX — AIRPOWER COMMAND
### Interactive Air Force Employment Exercise Training Simulator

Welcome to **AFEX — Airpower Command**, an interactive military-themed training game designed to help Officer Trainees learn the fundamentals of airpower employment, mission planning, force packaging, and command decision-making.

This educational simulator provides a visual and interactive environment for learning important AFEX concepts.

## 🕹️ GAME FEATURES

### 1. Command Center
An interactive mission dashboard featuring:
- Military-style command interface
- Interactive operations map
- Animated aircraft
- Mission score and readiness tracking
- Event logs

### 2. Learn AFEX
Beginner-friendly training covering:
- What AFEX is
- Mission planning fundamentals
- Force packaging
- Team coordination
- Mission execution
- After-action reviews

### 3. Mission Simulator
A six-turn interactive exercise where players:
- Review mission objectives
- Select support packages
- Make command decisions
- Manage resources
- Respond to changing situations
- Earn mission points

### 4. Decision Drills
Eight multiple-choice training questions featuring:
- Four answer choices
- One best answer
- Immediate feedback
- Explanations
- Performance tracking

### 5. After-Action Review
Review:
- Final mission points
- Completed turns
- Correct decisions
- Readiness level
- Lessons learned

## 📖 HOW TO PLAY

1. Open the AFEX game using the link above.
2. Select **LEARN AFEX** to understand the fundamentals.
3. Open **MISSION SIMULATOR**.
4. Read each mission scenario carefully.
5. Select your support package.
6. Choose the best command decision.
7. Review the explanation.
8. Advance to the next turn.
9. Complete all six turns.
10. Open **AFTER-ACTION REVIEW** to evaluate your performance.

Complete the Decision Drills to reinforce your knowledge.
